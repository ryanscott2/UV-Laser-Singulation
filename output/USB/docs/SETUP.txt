==============================================================
 DICING TOOLS - USB PACKAGE   (Windows 7, Python 3.8, offline)
==============================================================

WHAT'S IN THIS FOLDER
  optiscan.py            stage driver + jog/teach tool (needs pyserial)
  dice_wafer.py          one-button dicer, move -> mark (laser-gated)
  winlase_build_jobs.py  builds the WinLase .wlj jobs (needs pywin32)
  wheels\                offline pip packages (pyserial + pywin32)
  setup.bat              RUN ONCE - makes the venv and installs the packages
  activate.bat           DOUBLE-CLICK each session - opens an activated shell
  SETUP.txt              this file

REQUIREMENT
  Python 3.8.10 installed and on PATH. Check in a NEW PowerShell window:
      python --version        (should print: Python 3.8.10)

ONE-TIME SETUP
  1. Copy this whole folder onto the laser PC, e.g. into
     C:\Users\<you>\Desktop\UserJobs\GoodsonGroup\Ryan\python\
  2. Double-click  setup.bat  and wait for "Setup complete".
     It creates a "venv" folder here and installs pyserial + pywin32.

EACH SESSION
  1. Double-click  activate.bat  -> a PowerShell opens showing  (venv)
  2. Confirm the stage:
         python optiscan.py info
  3. Jog and record the four positions (saves optiscan_positions.json):
         python optiscan.py jog --step 500

  (activate.bat is just "set the script policy + activate the venv" in one
  click - the two steps you were typing by hand.)

IF "python" IS NOT RECOGNIZED
  PATH updates only reach NEW windows - close and reopen PowerShell.
  If still missing, the exe is here (use its full path):
     C:\Users\<you>\AppData\Local\Programs\Python\Python38\python.exe

IF optiscan.py SAYS  could not open port 'COM5': Access is denied
  Another program already has the port. In order:
    1. Close Prior's software, WinLase, and any serial terminal; retry.
    2. Unplug the OptiScan USB, wait 5 seconds, replug; retry.
    3. Device Manager > Ports (COM & LPT): confirm the stage's COMx.
       If it isn't COM5, add  --port COMx  to the command.
    4. Reboot, then run  optiscan.py info  BEFORE opening any other app.
  (Port settings 9600 / 8 / none / 1 / no flow control are correct - the
  script sets those itself, so a busy port, not settings, is the cause.)

LATER - FIRING THE LASER
  See the header of dice_wafer.py. It only fires with --arm (simulates by
  default). Keep optiscan.py and dice_wafer.py together in this folder.
